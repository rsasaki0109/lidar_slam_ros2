# lidarslam_ros2 v0.12.0

> **Release candidate status — HOLD; not published or tagged**

v0.12.0 is the next release candidate of the supported Humble and Jazzy
rosbag2-to-Autoware-compatible map workflow. [v0.11.0](v0.11.0.md) is the
latest published release; use its pinned `v0.11.0-humble` and
`v0.11.0-jazzy` images and its notes for the supported routes.

This file becomes the public GitHub Release body verbatim. The tag workflow
therefore refuses this candidate-only banner and the HOLD decision below. A
maintainer must first satisfy the release gates, replace them with the final
verification section, and commit that review before creating `v0.12.0`.

## Shortest supported paths

These are unchanged from v0.11.0:

- `lidarslam-map doctor`, then `lidarslam-map demo <new-output-dir>` for the
  fixed public MID-360 demo;
- `lidarslam-map doctor /path/to/rosbag2`, then
  `lidarslam-map start /path/to/rosbag2` for your own bag.

## Changes since v0.11.0

- **The two-system comparison tooling is retired.** The competitive
  benchmark stack, the M6a10 runtime phase contract, the GLIM clean-room
  adapter and the GLIM / FAST-LIVO2 comparison runners are removed. No
  release gate used them. The README and comparison results stay; rerun their
  comparisons from the `v0.11.0` tag.
- `scripts/run_rko_lio_graph_benchmark.sh --skip-map-save` still suppresses
  the graph's own map writes; the launch now reads
  `LIDARSLAM_BENCHMARK_NO_MAP_ARTIFACTS` instead of
  `M6A10_BENCHMARK_NO_MAP_ARTIFACTS`.
- The docs point at the published `v0.11.0-humble` and `v0.11.0-jazzy`
  images.

The full list is in
[CHANGELOG.md](https://github.com/rsasaki0109/lidar_slam_ros2/blob/develop/CHANGELOG.md).

## Release decision: HOLD

No release gate has run for this candidate yet. Before tagging, run on the
exact final commit:

- `bash scripts/run_product_python_tests.sh` and strict MkDocs;
- the fixed demo, `lidarslam-map doctor`, and bundle reproducibility;
- `bash scripts/run_release_readiness_checks.sh --fail-on-profiles` with
  exact-commit evidence for `newer_college_math_hard`, `ntu_viral_tnp_01`,
  `mid360_gt_rtkslam_construction_seq2`, `mid360_gt_rtkslam_construction_seq1`,
  and `leo_drive_applanix_velodyne_cross`. A fresh NTU VIRAL preparation starts
  with `bash scripts/download_ntu_viral_tnp01.sh --dry-run`.
  `newer_college_math_hard` was not measured for v0.11.0 (a recorded one-time
  exception); it is blocking again for this candidate.

Only results from that exact commit may replace this HOLD section and the
candidate banner.
