# lidarslam_ros2 v0.10.1

> **Release candidate status — HOLD; not published or tagged**

v0.10.1 is the next release candidate of the supported Humble and Jazzy
rosbag2-to-Autoware-compatible map workflow. [v0.10.0](v0.10.0.md) is the
latest published release; use its pinned `v0.10.0-humble` and `v0.10.0-jazzy`
images and its notes for the supported routes.

This file becomes the public GitHub Release body verbatim. The tag workflow
therefore refuses this candidate-only banner and the HOLD decision below. A
maintainer must first satisfy the release gates, replace them with the final
verification section, and commit that review before creating `v0.10.1`.

## Shortest supported paths

These are unchanged from v0.10.0:

- `lidarslam-map doctor`, then `lidarslam-map demo <new-output-dir>` for the
  fixed public MID-360 demo;
- `lidarslam-map doctor /path/to/rosbag2`, then
  `lidarslam-map start /path/to/rosbag2` for your own bag.

## Changes since v0.10.0

- The release workflow builds the release bundle before the standalone Docker
  launcher. The v0.10.0 run failed because the launcher wrote into the
  checkout the bundle requires to be clean.
- The documentation pins the published `v0.10.0` images, which carry the
  `lidarslam-map report` handoff and the own-bag `start` contract.
- v0.10.0 reported RKO-LIO v16's GEODE Hard median (8.5 m, against 78.7 m for
  BIEVR-LIO). The GEODE configurations were developed on those sequences, while the
  rivals ran their own configurations, so these numbers do not compare the methods on
  unseen data. On GEODE's held-out Metro Tunneling bags RKO-LIO has no failure, but
  BIEVR-LIO's median ATE is lower. See the [comparison page](../comparison.md).
