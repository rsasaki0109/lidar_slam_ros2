G13 = G12 + map_update_min_translation 0.1 (rko_lio 400fc3c): a registered scan is added to the map only after the
sensor has moved 0.1 m since the last scan that was added. While a sensor stands still it adds the same sampling
pattern again and again and fills the voxels (max_points_per_voxel 20); the scans after the start of motion then
register against that pattern (GrandTour ARC-3 with the Hesai: 0.126 -> 0.043 m, HEAP-1 0.0281 -> 0.0269 m).
