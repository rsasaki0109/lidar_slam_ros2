Phase 1, candidate G16 (fixed 2026-11-08, before any G16 run other than the opened blind-run mission PIL-1, where the
re-level was explored at 2, 3 and 5 deg and its results are known; report chapter 60.1).

G16 = G12 + gravity_window_alignment true, gravity_alignment_relevel_map true, gravity_alignment_relevel_min_tilt_rad
0.034907 (2 deg), the other gravity_* keys at rko_lio's defaults (20-s window, |g| within 5 %, intervals with a world yaw
rate above 0.05 rad/s left out). File: data/phase1_global/rko_lio_candidate_G16_2026-11-08.yaml. Build: the installed
rko_lio ac64178 (offline_node md5 cddcf9d9bb47dfceaa5eb92d579e87a3).
Every 20-s window measures the specific force's tilt from the world vertical; when it reaches 2 deg, the pose, the
previous pose, the local map and the window are rotated about the current position so that the measured tilt becomes
zero (one local-map rebuild). Below 2 deg nothing is applied, so a run whose frame never tilts that far is G12 byte for
byte (the window statistic is computed but not used). The plan (chapter 30.9) kept the gravity window off for public
data because the window cannot tell the accelerometer's own tilt (0.3-1.2 deg on the development data, chapter 30.8)
from attitude drift; 2 deg lies above that range. Self-adaptation from sensor data only, frozen here.

Why: in the first blind run (chapter 57) G12's world frame on GrandTour PIL-1 tilts to 8 deg from gravity (chapter
60.1), which turns every climb into too much height; with the 2-deg re-level, PIL-1's ATE 2.720 -> 1.302 m (median
1.32 -> 0.25 m).
