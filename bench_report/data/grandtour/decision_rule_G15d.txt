GrandTour HS configuration G15d (fixed 2026-10-28 before any G15d run other than those of the twelfth and thirteenth
HS screens, screen_hs_l_2026-10-28/ and screen_hs_m_2026-10-28/, and of the noise diagnostic, noise_2026-10-28/, whose
results are known and count with these runs).

G15d = HS-G15c (configs/sota_v7/rko_lio_grandtour_hs_G15c_2026-10-27.yaml) + start_standstill_radius 1.0 +
start_standstill_hold true + start_standstill_hold_radius 0.05 + start_standstill_bias interval +
start_standstill_bias_static_only true (rko_lio 6b0a460, ws/rko_g26; confirm_G15d_2026-10-28/g15d.yaml, the
thirteenth screen's r5is with only its comment line changed). While the robot stands within 1 m of its start, a
scan's registered position is clamped to 5 cm around the position where it first stood and the map is not updated
with a clamped scan; after a static start the standing intervals set the gyro and accelerometer biases, after a
moving start they leave them at zero. A configuration for the HS rig of GrandTour only, like G15c.

Why: on the nine missions of the thirteenth screen it lowers the mean from 0.0180 to 0.0166 m, mostly through SNOW-3
(0.0268 -> 0.0156; people pull the registration while the robot stands for about 8 s) and HEAP-1 (0.0238 -> 0.0205).
Its only mission outside the 10 % / 2 mm tolerance there, ARC-5 (0.0152 -> 0.0173), is within the spread of neutral
changes: over four stopping thresholds the means are 0.0170 (G15c) and 0.0171 (r5is).

Adopt G15d as the GrandTour HS configuration in place of G15c if all of these hold (frontend only):
  1. The 15 HS development missions of decision_rule_G15b.txt, one run each (the default file): mean below G15c's
     0.0184 m. snow-1 is run and reported only.
  2. No mission worse than G15c by more than 10 % and more than 2 mm at once, judged in two stages. First on the
     single runs. A mission outside the tolerance there is run three more times with each configuration, with
     convergence_criterion 2.5e-5, 3.5e-5 and 4.0e-5 in place of 3.0e-5 (nothing else changed), and judged again,
     with the same tolerance, on the means of the four runs of each configuration; it fails only if it is outside
     the tolerance on those means as well. ARC-5's four-run means are known (0.0170 / 0.0171); this stage was
     written after them, and ARC-5 passes by it.
  3. Every run real-time (node time below the mission span).

arc-1, arc-3 (r5i of the twelfth screen, which r5is reproduces byte for byte on static starts, checked on heap-1).
