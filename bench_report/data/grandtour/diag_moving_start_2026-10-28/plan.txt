Diagnostic: why the re-estimated gravity costs ARC-5's height (2026-10-28, written before these runs; adopts nothing).

In the fifth screen the gravity of a moving start was estimated correctly (ARC-5 16.10 deg, the IMU-based measure
16.2), yet ARC-5's ATE grew 0.0152 -> 0.0180 m, mostly in height. Hypothesis: with the right gravity the orientation
regularization (min_beta 200: the attitude is pulled so that the predicted gravity matches the IMU's specific force
less the body-acceleration filter's estimate) acts as intended, and on this legged robot that measured gravity is
noisy enough to tilt the attitude and so the height; in the 16-deg frame it was pulling towards a wrong vertical
that the registration held, so it did less. (G12's first screen: min_beta 1e9 helped ARC-5, 0.0554 -> 0.0346 m.)
Variants (ws/rko_g21): nograv = G15b + min_beta 1e9; mg5nograv = G15b + moving_start_gravity_window_sec 5.0 + min_beta
1e9. Mission: arc-5; arc-4 and snow-3 (the other moving starts with a few degrees of tilt) if arc-5 supports it.
Compared with G15b 0.0152 and mg5 0.0180 (arc-5). If mg5nograv is not worse than nograv, the regularization explains
the loss; a candidate that follows from this gets its own screen and rule.

Result (2026-10-28; ws/rko_g21; arc-5, ATE without reference spikes, m): G15b 0.0152, mg5 0.0180, nograv 0.0192,
mg5nograv 0.0205. The regularization helps in both frames, so it does not explain the loss; without it the right
gravity is still worse. The difference is almost all in the 200-220 s window, the first after a 120-s stretch with no
reference (80-200 s, indoors): it is how far the height drifted there (z 16.7 mm for G15b, 29.8 / 33.3 / 39.1 for the
others). ARC-5 moves by several mm with any small change (G12 0.0554, bump alone 0.0120), so one mission cannot settle
the re-estimated gravity. The test's two moving starts are tilted by only about 2.1 deg (SNOW-2) and 2.3 deg (SPX-2)
(the output's frame against the STIM320's specific force, no reference read), like ARC-4 and SNOW-3 here, where mgof2
gained 0.7-1.2 mm. Not pursued further for now: the start of SNOW-3 costs far more (screen_hs_h_2026-10-28).
