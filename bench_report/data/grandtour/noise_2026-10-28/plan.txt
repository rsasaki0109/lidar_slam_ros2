Run-to-run spread of the ATE under numerically neutral changes (2026-10-28, written before these runs; a diagnostic
that adopts nothing).

Why: ARC-5 moves by 1-4 mm with every start variant tried (0.0152 G15c; 0.0156, 0.0166, 0.0173, 0.0180, 0.0196 with
others), mostly through the height drift over its 120-s stretch without reference, and the thirteenth screen's r5is
breaks the 10 % / 2 mm tolerance there by 0.1 mm (0.0173). The runs are deterministic (repeated runs give the same md5),
but the TBB thread count changes the order of the floating-point sums in the registration, so it perturbs a run
without changing what it computes. The spread over max_num_threads 1, 2, 3 (the default 0 uses all four cores) is
a measure of how much of a mission's difference is chaos rather than method.
Runs (ws/rko_g26, whose behaviour with G15c's file is G15c's): arc-5 with G15c and with r5is at max_num_threads 1, 2,
3; arc-3 with G15c at max_num_threads 1, 2, 3. Reported: ATE without reference spikes, with the default runs (G15c
arc-5 0.0152, arc-3 0.0190; r5is arc-5 0.0173).
Amendment (2026-10-28, after the first run): the thread count is not a perturbation: G15c on arc-5 with
max_num_threads 1 gives the default run's file byte for byte (md5 5991b7bb...; threads/g15c_t1.yaml); the other
thread runs were stopped and removed. The perturbation is now the ICP convergence threshold (convergence_criterion
3.0e-5 in both files) at 2.5e-5, 3.5e-5 and 4.0e-5: it changes when the iterations stop, not what they minimise.
Runs: arc-5 with G15c and r5is at the three values; arc-3 with G15c at the three values.

Result (2026-10-28; ws/rko_g26; ATE without reference spikes, m; convergence_criterion 3.0e-5 (default run) / 2.5e-5 /
3.5e-5 / 4.0e-5, and the four-run mean):
  arc-5  G15c  0.0152 / 0.0163 / 0.0185 / 0.0180   mean 0.0170
  arc-5  r5is  0.0173 / 0.0156 / 0.0179 / 0.0174   mean 0.0171
  arc-3  G15c  0.0190 / 0.0217 / 0.0209 / 0.0208   mean 0.0206
A neutral change of the stopping threshold moves a mission by up to 3.3 mm (arc-5 G15c 0.0152 -> 0.0185) and 2.7 mm
(arc-3 G15c 0.0190 -> 0.0217): as much as most of the differences the screens judged. On arc-5 the default run is
G15c's best of four and r5is's third; their means differ by 0.1 mm, so r5is's single-run loss there (+2.1 mm) is
chaos, not method. G15c's default runs on these two missions sit at the low end of their spread, which also lowers
G15c's reference mean (0.0184) a little against any later variant judged on single runs.
